# Command: benchmark

Compare the target against one or two category leaders and produce a ranked gap list. Steals the
patterns that work; never copies pixels.

## Steps

1. Pick references: ask the user which product(s) they admire for this job, or propose from the
   category (state why — e.g., "Linear for issue triage density, Stripe for Configure clarity"). One or
   two, never more.
2. Load or open the references and analyze the same ten dimensions as `critique`: job clarity,
   scanability, density, hierarchy, consistency, states, copy, efficiency, craft, register fit.
3. For each dimension, capture *transferable mechanisms*, not pixels: "row height 36px with hairline
   separators and frozen first column", "filters as chips with live result count", "empty state carries
   the primary action". Note what the leader does worse, too — you are not flattering them.
4. Diff against the target: for each mechanism, is the target missing it, at parity, or ahead?
5. Deliver: a table (mechanism | leader | target status | steal? yes/no with reason) and a ranked
   top-5 adoption list with effort estimates (small/medium/large) and the job each improves.

## Rules

- Never copy visuals — copy the reasoning and rebuild it in the target's own system.
- Only mechanisms that fit the target's register, density tier, and stack get recommended.
- If the leader's pattern conflicts with the brief or craft floor, say so and drop it.
- The output is a plan; no code until the user picks.
