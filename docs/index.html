Impeccable craft skills

Ten agent skills that give AI coding agents expert judgment instead of defaults — one facet of building software each, all in the same pattern: a command vocabulary, domain knowledge, a quality floor, anti-pattern tells, and a deterministic checker.

The pattern

skill/<name>/
├── SKILL.md            # persona · principles · command table · routing
├── scripts/            # deterministic checker (+ live daemon for criterion)
├── reference/          # quality floor · anti-patterns · domains · commands
├── assets/             # shipped context templates
└── tests/              # behavioral scenario harness
