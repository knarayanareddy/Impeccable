Obscraft

The craft skill for observability that tells the truth. Logs that lie are worse than no logs. Every page wakes a human who can act.

Install

npx skills add knarayanareddy/Impeccable --skill obscraft

Then /obscraft slo checkout, /obscraft alert ., or any of the 15 commands.

Telemetry-check — the question-first gate

node skill/obscraft/scripts/telemetry-check.mjs --slos slo.yaml --alerts alerts.yaml --metrics metrics.json
# GAP slo   missing-owner   SLO "checkout-availability" has no owner
# GAP alert missing-runbook Alert "CheckoutFastBurn" has no runbook
# telemetry-check: 2 gap(s) · FAILED

The SLO quartet, the alert actionability contract, and the metric vocabulary — mechanical, CI-ready. A file that parses to zero entries refuses, never claims valid.

SLO/alert review daemon

node skill/obscraft/scripts/slo-review.mjs --review review.json --round r1 &
node skill/obscraft/scripts/slo-review.mjs --round r1 --wait

Serve every SLO and alert as a decision page; gaps (no owner, no runbook) are shown in red.
