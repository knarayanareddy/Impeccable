Testcraft

The craft skill for test suites that mean what they say. Tests are executable specifications. Confidence, not numbers.

Install

npx skills add knarayanareddy/Impeccable --skill testcraft

Then /testcraft flaky ., /testcraft strengthen src/cart, or any of the 16 commands.

The checker

node skill/testcraft/scripts/check.mjs --strict --target src/
# ERROR focused-test           checkout.test.ts:6   it.only(
# ERROR tautological-assertion checkout.test.ts:7   expect(true) toBe true
# WARN  skipped-test           checkout.test.ts:10  it.skip(
# testcraft: 42 test file(s) scanned · FAILED

Zero dependencies, no LLM, no API key. Behaviors pinned by 19 automated scenarios.

Suite health — the aggregate view

node skill/testcraft/scripts/suite-health.mjs --target . --history history.json
# Worst files: 4  src/checkout.test.ts · 2  src/feed.test.tsx
# By rule: 3 focused-test · 2 retry-mask · 1 skipped-test

Ranked report plus a trend record — the focus/skip/flake debt over time.

Flake review daemon

node skill/testcraft/scripts/flake-review.mjs --flakes flakes.json --round r1 &
node skill/testcraft/scripts/flake-review.mjs --round r1 --wait

Serve the flakiest tests as a triage page: fix now / quarantine + ticket / known external. Retry-masking is not on the menu.
