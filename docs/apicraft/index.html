Apicraft

The craft skill for APIs that feel like promises kept — REST, GraphQL, gRPC, webhooks. An API is a promise, not an endpoint. Judge from the consumer's code.

Install

npx skills add knarayanareddy/Impeccable --skill apicraft

Then /apicraft contract orders, /apicraft audit ., or any of the 16 commands.

The checker

node skill/apicraft/scripts/check.mjs --strict --target src/
# ERROR verb-in-url           routes.js:7   /api/getUser
# ERROR hardcoded-credential  config.js:5   apiKey = "<redacted>"
# WARN  unbounded-page-size   orders.js:10  10000
# apicraft: 14 file(s) scanned · FAILED

Plus spec-lint: operations missing responses or operationIds. Zero dependencies, no LLM, no API key. Behaviors pinned by 30 automated scenarios.

Contract-diff — breaking changes, mechanically

node skill/apicraft/scripts/contract-diff.mjs openapi/v1.yaml openapi/v2.yaml
# BREAKING removed-operation        POST /orders   consumers calling this endpoint break
# BREAKING changed-property-type    Order.total_cents  integer → string
# contract-diff: 2 breaking change(s)

The floor's cardinal sin — silent breaking changes — caught by a machine, CI-ready (--json, exit codes).

Contract review daemon

node skill/apicraft/scripts/review.mjs --spec openapi.yaml --round r1 &
node skill/apicraft/scripts/review.mjs --round r1 --wait

Serve every endpoint as a review page; the human approves or flags each from the consumer's seat.
