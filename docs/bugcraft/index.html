Bugcraft

The craft skill for debugging that finds causes, not coincidences. Every bug is found by evidence, not by luck. Reproduce, bisect, pin.

Install

npx skills add knarayanareddy/Impeccable --skill bugcraft

Then /bugcraft repro checkout-hang, /bugcraft diagnose ., or any of the 15 commands.

Zero dependencies, no LLM, no API key. Behaviors pinned by 39 automated scenarios.

repro-check — the evidence gate

node skill/bugcraft/scripts/repro-check.mjs --bugs bugs.yaml
# GAP missing-steps          Bug "CHECKOUT-31" has no steps/repro path
# GAP missing-pin            Bug "CHECKOUT-31" is fixed with no pin
# repro-check: 12 gap(s) · FAILED

The repro-signature quartet (observed, expected, steps, environment), the evidence rung, and the closure contract — mechanical, CI-ready. A file that parses to zero records refuses, never claims the floor holds.

Bug review daemon

node skill/bugcraft/scripts/bug-review.mjs --bugs bugs.json --round r1 &
node skill/bugcraft/scripts/bug-review.mjs --round r1 --wait

Serve every bug as a decision page — close / flag / n-a — with the closure gaps in red: no repro, no root-cause, no pin.
