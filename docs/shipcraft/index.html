Shipcraft

The craft skill for delivery systems that make shipping boring. The pipeline's job is to make shipping boring. A deploy is a promise you keep in production.

Install

npx skills add knarayanareddy/Impeccable --skill shipcraft

Then /shipcraft pipeline ., /shipcraft audit ., or any of the 15 commands.

The checker

node skill/shipcraft/scripts/check.mjs --strict --target .
# ERROR secret-echo      ci.yml:6   Secret echoed in a pipeline step
# ERROR masked-failure   ci.yml:5   Red mask — the step's failure is swallowed
# WARN  pipe-to-shell    ci.yml:7   curl | sh
# WARN  latest-tag       ci.yml:8   docker build -t app (untagged = latest)
# shipcraft: 17 delivery file(s) scanned · FAILED

Zero dependencies, no LLM, no API key. Behaviors pinned by 43 automated scenarios.

ci-check — the pipeline gate

node skill/shipcraft/scripts/ci-check.mjs --pipeline .github/workflows/ci.yml --strict
# ERROR masked-failure   step-2 · 1   npm test || true
# WARN  deploy-without-rollback        Deploy steps with no rollback reference
# ci-check: 6 step(s) · GATE FAILED

Parses the workflow into steps (GitHub Actions, GitLab CI, Azure, CircleCI — or native JSON) and gates every step with the same vocabulary. A file that parses to zero steps refuses, never claims the gate holds. Built to sit in CI: the gate that gates its own pipeline.

Pipeline review daemon

node skill/shipcraft/scripts/pipeline-review.mjs --steps steps.json --round r1 &
node skill/shipcraft/scripts/pipeline-review.mjs --round r1 --wait

Serve every deploy step as a decision page — ship / flag / n-a — with the gaps in red: no rollback reference, or high-risk without an approval reference.
