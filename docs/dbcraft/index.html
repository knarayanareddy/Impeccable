Dbcraft

The craft skill for schemas that stay true for a decade. Data outlives code. The schema is the longest-lived interface in the system.

Install

npx skills add knarayanareddy/Impeccable --skill dbcraft

Then /dbcraft constrain ., /dbcraft migrate, or any of the 16 commands.

The checker

node skill/dbcraft/scripts/check.mjs --strict --target migrations/
# ERROR missing-primary-key   users.sql — identity and integrity require one
# ERROR float-for-money      balance FLOAT — binary floats cannot represent decimal money
# WARN  varchar-255-sprawl   4 × VARCHAR(255) — a habit, not a decision
# dbcraft: 14 file(s) scanned · FAILED

With CREATE TABLE block parsing. Zero dependencies, no LLM, no API key. Behaviors pinned by 30 automated scenarios.

Schema-diff — destructive migrations, mechanically

node skill/dbcraft/scripts/schema-diff.mjs v1.sql v2.sql
# BREAKING dropped-column      orders.legacy  add, dual-write, switch, drop later
# BREAKING changed-column-type orders.total    BIGINT → DOUBLE PRECISION
# schema-diff: 2 breaking change(s)

The floor's cardinal sin — destructive migrations — made visible by a machine, CI-ready.

Migration review daemon

node skill/dbcraft/scripts/migration-review.mjs --steps steps.json --round r1 &
node skill/dbcraft/scripts/migration-review.mjs --round r1 --wait

Serve a migration's steps as a review page; the human verdicts each against the migration checklist.
