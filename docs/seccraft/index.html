Seccraft

The craft skill for security that is designed, not bolted on. Security is the design of failure, not a final scan. Trust is explicit.

Install

npx skills add knarayanareddy/Impeccable --skill seccraft

Then /seccraft threatmodel orders, /seccraft authz src/api, or any of the 16 commands.

The checker

node skill/seccraft/scripts/check.mjs --strict --target src/
# ERROR hardcoded-credential config.js:5  apiKey = "<redacted>"
# ERROR interpolated-sql     routes.js:12  python .format() SQL
# WARN  weak-jwt             auth.js:3     hardcoded JWT secret
# seccraft: 14 file(s) scanned · FAILED

Zero dependencies, no LLM, no API key; values redacted in output. Behaviors pinned by 24 automated scenarios.

Lock-check — the secure-defaults gate

node skill/seccraft/scripts/lock-check.mjs --config config.json

# GAP cors     origin origin "*" on an authenticated API

The lock command's checklist as a deploy gate — CI-ready.

Threat review daemon

node skill/seccraft/scripts/threat-review.mjs --threats threats.json --round r1 &
node skill/seccraft/scripts/threat-review.mjs --round r1 --wait

Serve the threat model's STRIDE entries as a decision page: control holds / mitigate / accept risk / escalate. Gaps cannot leave silently.
