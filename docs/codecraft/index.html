Codecraft

The craft skill for code that reads like a senior engineer wrote it — any language. Code is read ten times more than it is written. Simplify or justify.

Install

npx skills add knarayanareddy/Impeccable --skill codecraft

Then /codecraft review src/api, /codecraft simplify src/payment, or any of the 17 commands.

Zero dependencies, no LLM, no API key. Its behaviors are pinned by 24 automated scenarios — checker rules, exemptions, windowed detection, comment stripping, the hooks manager, and the live daemon.

node skill/codecraft/scripts/hooks.mjs on --apply   # wire the checker into PostToolUse
node skill/codecraft/scripts/hooks.mjs status        # wired or not?

Refactor variant mode

node skill/codecraft/scripts/live.mjs --round simplify --options a.json b.json &
node skill/codecraft/scripts/live.mjs --round simplify --wait
