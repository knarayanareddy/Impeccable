Criterion

The design skill for interfaces that do work — dashboards, admin panels, tools, tables, charts, forms. Design for the second hour, not the first impression. Measure, don't vibe.

Install

npx skills add knarayanareddy/Impeccable --skill criterion

Then /criterion audit dashboard, /criterion densify tickets, or any of the 22 commands.

Zero dependencies, no LLM, no API key. It also ships as a browser extension that scans any live page, and its behaviors are pinned by 17 automated scenarios.

Live iteration

node skill/criterion/scripts/live.mjs --round density --options a.json b.json &
node skill/criterion/scripts/live.mjs --round density --wait

Serve a decision page, let the user pick the variant, and the daemon records the choice for the agent.
