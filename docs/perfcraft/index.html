Perfcraft

The craft skill for performance that is measured, budgeted, and owned. Measure before you optimize. The user's clock is the only clock.

Install

npx skills add knarayanareddy/Impeccable --skill perfcraft

Then /perfcraft profile src/checkout, /perfcraft budget ., or any of the 17 commands.

The commands 17

Evaluateaudit · profile · measure · review · optimize-review (daemon)

Budget-check — the gate, mechanically

node skill/perfcraft/scripts/budget-check.mjs --budget budget.json --measurements m.json
# BREACH resource-size  script: 310KB > budget 200KB
# BREACH metric         LCP: 2700 > budget 2500ms (p75)
# budget-check: 2 breach(es) · FAILED

The perf floor's "budgets in CI" as a tool — and its shape rule fires on any budget whose metric lacks a percentile.

Optimization review daemon

node skill/perfcraft/scripts/optimize-review.mjs --options options.json --round r1 &
node skill/perfcraft/scripts/optimize-review.mjs --round r1 --wait

Verdict optimization candidates on their measured receipts — options without before/after numbers are rejected at load. No number, no option.
